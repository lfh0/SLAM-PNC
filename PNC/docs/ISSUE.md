# 当前问题清单

## ISSUE-LA-001：局部 A* 将超时与真正无路混为同一状态

- 状态：代码已解决，待仿真场景验收
- 优先级：高
- 影响：运行态会显示`FAILED:ASTAR_NO_PATH`，但该状态既可能是开放集为空，也可能是到达搜索时间预算；不能据此判断地图无路。

根因已经确认：旧A*将`max_search_time`按毫秒比较，局部配置的`0.05`实际只有`0.05 ms`，并不是预期的`0.05 s`。现已改为显式参数`local_astar/max_search_time_ms: 50.0`，使用`ros::WallTime`计时；A*新增独立`TIMEOUT`返回值，LA-03映射为`FAILED:ASTAR_TIMEOUT`，仅开放集耗尽等确定失败输出`FAILED:ASTAR_NO_PATH`。旧参数名仍按毫秒兼容，避免破坏既有全局配置。

验收：构造可达但超过预算的场景得到`ASTAR_TIMEOUT`；构造封闭障碍场景得到`ASTAR_NO_PATH`；两者均不得发布候选路径。

## ISSUE-LA-002：动态局部地图的版本失效与搜索取消尚未实现

- 状态：过期结果隔离已解决，A*搜索过程中的协作式取消未实现
- 优先级：高
- 影响：LA-03每次搜索使用一份固定地图快照；搜索期间新costmap到来时，完成结果可能已过期。

LA-03候选现携带`episode_id`和地图内容版本；局部优化请求管理器在最新costmap上重新逐段检查候选，过期但在最新地图仍安全的路径可继续使用，已经碰撞的候选不得进入MINCO。优化中或已提交的几何路径被新地图判为碰撞时，立即发布同一`episode_id/request_id`的`CANCEL`并回到`SEARCHING`。A*搜索本身仍是同步短预算调用，搜索期间不做协作式取消；其输出由后级最新地图校验隔离，因此不会把旧地图结果直接送入局部MINCO。最终接管仍必须由LA-05/F5以完整车辆模型复检。

验收：搜索期间更新局部地图，旧版本结果若与最新地图冲突不得产生`OPTIMIZE`请求；优化期间地图侵入路径必须产生`CANCEL`。A*内部提前退出可作为后续性能增强，不再是安全结果隔离的前置条件。

## ISSUE-LA-003：安全重汇入终点尚未按连续安全段选择

- 状态：未解决
- 优先级：高
- 影响：当前终点按首个阻断点之后的固定弧长`rejoin_distance_after_blockage_m`选取，可能仍位于障碍、未知区或完整车辆碰撞区，造成`HybridAstar goal footprint is in collision`。

需要从阻断后最小距离开始，沿全局参考扫描，选择第一个完整车辆footprint无碰撞且其后连续安全段足够长的点作为重汇入目标；找不到时输出`NO_SAFE_REJOIN_TARGET`。

验收：长障碍、弯道贴障和未知区域场景均不会把碰撞点作为目标；无安全重汇入点时明确失败。

## ISSUE-LA-004：阻断检测与Hybrid A*车辆模型/阈值未统一

- 状态：未解决
- 优先级：高
- 影响：当前运行态已观测到LA-02 footprint约为`0.6 x 0.5 m`，而共享Hybrid A*配置为`1.2 x 1.0 m`；LA-02阈值与LA-03阈值也可能不同。模块会对同一位置得出不同可行性结论。

需要冻结一份实际车辆几何、参考原点和代价阈值，并供LA-02、Hybrid A*、局部MINCO、F5统一使用。A*模式按用户决定不做额外footprint膨胀，但仍须由后续F5以统一车辆模型复检。

验收：同一地图、同一姿态下各模块的占据/可行性结论一致。

## ISSUE-LA-005：局部 A* 耗时与重复触发控制尚未验收

- 状态：重复触发与计时问题已修复，动态取消仍由ISSUE-LA-002跟踪
- 优先级：中
- 影响：完整局部地图搜索、5 m重汇入距离、10 Hz定时器和高cost软代价可能导致连续重复搜索。现有A*基于`ros::Time`计时，在仿真时钟条件下并非严格墙钟预算。

已改用`ros::WallTime`，成功或失败日志均给出单次总墙钟耗时，A*核心超时日志同时给出扩展次数。节点对costmap实际内容、地图几何以及A*起终点栅格生成请求签名：仅时间戳变化不会重复搜索，地图内容或起终点栅格变化会立即形成新请求；阻断状态退出`REPLAN_REQUIRED`后会清空签名，确保下一次重规划事件可再次执行。搜索中到达的新地图版本取消/结果废弃仍未实现，继续由ISSUE-LA-002跟踪。

同时修复了A*开放集的降代价更新：旧实现直接修改队列内节点的`f_score`但没有重新入队，破坏`priority_queue`堆序；现改为不可变优先级快照和惰性丢弃旧条目。A*模式也不再提前构造仅Hybrid A*使用的二值地图。

验收：相同输入不重复搜索；新版本可取消旧任务；日志能区分排队、搜索、取消和发布耗时。
